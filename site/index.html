Why Sovereign?

Built for power users who care about privacy.

Zero-Cost Memory

Written in Rust. Runs in the background using < 1% CPU and minimal RAM. Unlike Python alternatives, it won't drain your battery.

Local-First AI

Uses local Tesseract OCR and on-device vector embeddings. No data ever leaves your machine. No API keys required.

Smart Blacklist

Automatically pauses recording when you open Incognito windows, Bitwarden, or 1Password. You stay in control.
